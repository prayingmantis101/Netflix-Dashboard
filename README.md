# Netflix-Dashboard

https://github.com/prayingmantis101/Netflix-Dashboard

Netflix Content Analytics Dashboard

An interactive Power BI data visualization project analyzing Netflix's global content library, genre distributions, rating classifications, release trends, and geographical content reach till 2021.   

Features & Visualizations

Key Performance Indicators (KPIs):
Total Titles: 5,331 titles   
Genres Covered: 70 distinct genres   
Locations: Content originating across 175 global locations   
Content Type Breakdown: Donut chart highlighting the proportion between Movies (97.08%) and TV Shows (2.92%).
Genres by Total Titles: Horizontal bar chart listing top categories (e.g., International Movies, Dramas, Comedies, Action & Adventure, Independent Movies, Thrillers).  
Rating by Total Titles: Breakdown of content classification by rating (e.g., TV-MA, TV-14, R, PG-13) cross-referenced by content type. 
Shows by Release Year: Column chart mapping production trends over time from ~1942 to recent years.  
Geographic Distribution: Interactive map powered by Bing Maps showcasing title availability and geographic origin across continents. 

Prerequisites & Installation
Download and install Power BI Desktop.
Clone this repository:
git clone https://github.com/prayingmantis101/Netflix-Dashboard
Open the file netflix.pbit in Power BI Desktop.
